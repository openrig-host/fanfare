Fanfare Privacy Policy

Last updated: November 9, 2026

Fanfare is a free desktop application for live music performance. It has no accounts, no sign-up, and no advertising. This policy explains exactly what data the app handles, which is very little.

What Fanfare collects

Nothing. Fanfare does not collect, transmit, sell, or share any personal information. There is no telemetry, no analytics, no tracking, and no crash reporting to us. The app runs entirely on your computer.

What stays on your computer

Everything you create or load stays on your machine: songs, setlists, rig settings, audio files, break-music decks, logs, and crash dumps (stored locally in your application data folder). None of this is uploaded anywhere.

The only times Fanfare connects to the internet

  • Update check. The app contacts GitHub (api.github.com) to compare version numbers so it can tell you when a newer release exists. The request contains nothing about you beyond what any normal web request carries. Opening the update page opens GitHub in your browser.
  • Downloading break music (optional, only when you use it). If you use the built-in YouTube download feature, the app fetches the video's title from YouTube and downloads the open-source yt-dlp tool from GitHub. These requests happen only when you ask for them, and only involve the video you chose.
  • Help and links. Buttons that open the manual, release notes, or support pages open your web browser.

That is the complete list. Fanfare never sends your music files, settings, MIDI input, or any other personal data to the internet.

Local network remote (optional, only when enabled)

Fanfare can run a small server on your computer so a tablet or phone on your own Wi-Fi network can act as a performance remote (the Stage HUD). This server listens only on your local network, only while you enable it, and only serves the control screen. Nothing is sent to the internet, and remote access stops when you close the app or turn the feature off.

Children

Fanfare is a general-purpose music tool, not directed at children. It does not knowingly collect information from anyone, including children, because it does not collect information at all.

Changes to this policy

If the app ever changes how it handles data, this page will be updated and the release notes will say so. The policy above reflects the current release.

Contact

Questions about this policy can be raised on the project's GitHub Discussions page.
